What is Claude Code?

AI coding assistant that works directly in the terminal

Growing Trend: Non-developers (POs, designers, analysts) are using Claude Code and Cursor to automate daily tasks!

For Engineers

  • Write & review code
  • Fix bugs, refactor
  • Build features

For Non-Developers

  • Automate data tasks
  • Generate reports
  • Build simple tools
  • Create prototypes

The barrier to automation is lower than ever

Three Working Modes

✏️ Edit Mode

Default working mode - Claude reads, writes, and modifies code files

✅ Accept Edit Mode

Review changes before applying - you maintain control

📋 Plan Mode

Creates detailed plans for large tasks - get approval before coding

Essential Commands

Quick Actions

  • Shift+? - Cheatsheet
  • @filename - Reference files
  • / - Command panel

Context Management

  • /context - See what Claude knows
  • /compact - Compress history
  • /clear - Fresh start
  • /rewind - Undo changes

Custom Commands

Teams can create their own commands for workflows

/wizact-dev-essentials:commit-message - Generate standardized commit messages

🧠

Context Window

Claude's "working memory" - the information it can actively think about

  • Like desk space - finite but large
  • "Forgot the middle" problem - long conversations lose detail
  • Solution: Use /compact or /clear regularly
  • Reference files with @ instead of pasting code

Two Types of Memory

📄 CLAUDE.md

Long-term (Permanent)

  • Team standards
  • Product terminology
  • User personas
  • Testing requirements
  • Business rules

🔖 # (Hashtag)

Session-based (Temporary)

  • Conversation summaries
  • Continue previous work
  • Share context with team
  • Workflow continuity

Typical Workflow

  • 1. Request: "Add payment processing feature"
  • 2. Claude enters Plan Mode → creates implementation plan
  • 3. You approve plan
  • 4. Agents work in parallel (backend, frontend, tests)
  • 5. Uses skills, MCP, CLAUDE.md throughout
  • 6. You review in Accept Edit Mode
  • 7. Commit created, PR opened

Agents vs Skills vs Commands

Feature Agents Skills Commands
Purpose Complex autonomous tasks Focused workflows Control Claude Code
Autonomy High - explores & plans Medium - executes workflow Low - immediate action
Invocation Automatic or /agents skill-name /command-name

Best Practices for Product Owners

Start Well

  • Reference files with @
  • Include acceptance criteria
  • Link to designs/tickets

Manage Context

  • Use /compact regularly
  • Document in CLAUDE.md
  • Use # for continuity

Leverage Tools

  • Explore agent for "how does X work?"
  • Plan agent for large features
  • Skills for common tasks

Build Knowledge

  • Update CLAUDE.md regularly
  • Create custom agents/skills
  • Share useful MCPs

Key Takeaways

💡
  • Speed: Faster iteration without sacrificing quality
  • Consistency: CLAUDE.md ensures standards are followed
  • Integration: Works with your existing tools (Figma, Jira, etc.)
  • Control: You review and approve all changes
  • Context: Product knowledge embedded in workflow
  • Accessibility: Non-developers can automate tasks too

Claude Code augments your team, not replaces human judgment
